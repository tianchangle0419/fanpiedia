# 反派影评 · 档案索引

「反派影评」听友自建的非官方文字索引：从一部电影、一位嘉宾出发，立刻定位它出现在哪几期节目。

## 数据

- 来源：听友维护的反派影评 RSS（长节目 + 马后炮 + 耳旁风，shownotes 自动解析）
- 范围：长节目 №001–№239（2016-04 ~ 2024-08）+ 马后炮 MA000–MA146（2016-07 ~ 2024-08）+ 耳旁风 ER001–ER322（2016-05 ~ 2024-07）+ 各系列 SP/杂谈，共 778 期
- 规模：约 4000 部电影、67 位嘉宾、约 8000 条片目提及
- 豆瓣补充：原名 / 年份 / 导演中外文名来自豆瓣（约 89% 已关联豆瓣条目；未匹配多为豆瓣未收录或已下架，如《天注定》《夹边沟》《返校》）
- 清洗规则：去除了「3D」后缀、尾部序号（阿凡达1→阿凡达）、简称改正式名（变5→变形金刚5：最后的骑士）、剔除非电影条目（反派影评/综艺/人名等）；电影合集（如「死侍1-2」）已拆分为单部并分别关联豆瓣
- 说明：马后炮 / 耳旁风的片目由 shownotes 正文自动提取《片名》，覆盖度低于长节目；耳旁风单评期以 shownotes 开头『全名』确定主聊影片
- 生成：`src/data/generated/archive.json`（由解析脚本从 RSS 生成，可重新跑脚本更新）

## 功能

- 全局搜索：片名 / 拼音 / 英文名 / 导演（中外文名）/ 嘉宾 / 期号（支持 no239、ma146、er100 直达）
- 节目目录：长节目 / 马后炮 / 耳旁风 三系列筛选，日期排序
- 电影索引 A–Z：按拼音首字母分组，标注原名、年份、导演与「主聊 N 期 · 提及 M 期」
- 电影详情：导演（中文 + 外文名，可跳转导演页）、豆瓣条目外链、专题主聊与片目提及分组列出
- 导演索引 / 详情：作品列表、作品被提及的全部节目（跨三系列聚合）
- 嘉宾索引 / 详情：出场期数与节目列表
- 节目详情：本期片目、主播与嘉宾、同系列上下期导航

## 技术

React + TypeScript + Vite + Tailwind CSS，HashRouter 纯前端，PWA 可安装。

```bash
npm run build   # 构建到 dist/
npm run dev     # 本地开发
```
